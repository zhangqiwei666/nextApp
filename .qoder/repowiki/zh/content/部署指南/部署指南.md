## 简介

本指南提供了完整的应用部署解决方案，涵盖Vercel云部署、自托管服务器配置和Docker容器化部署三种方式。项目基于Next.js 16框架构建，采用TypeScript开发，具有现代化的前端架构和灵活的部署选项。

## 核心组件

### 构建配置系统

项目使用Next.js 16的现代化配置系统，支持多种部署场景：

- **基础路径配置**: 支持通过环境变量控制basePath，便于反向代理部署
- **图像优化**: 配置远程图像源，支持HTTPS和HTTP协议
- **缓存优化**: 启用Cache Components功能，提升组件渲染性能
- **API代理**: 内置rewrites配置，支持外部后端服务代理

### 请求处理系统

统一的API请求封装提供了完整的HTTP通信能力：

- **类型安全**: 完整的TypeScript类型定义
- **环境适配**: 自动区分客户端和服务端环境
- **认证支持**: 自动处理token注入和认证头
- **错误处理**: 统一的错误处理和业务逻辑分离

## 详细组件分析

### 代理中间件组件

代理中间件实现了全局路由拦截和鉴权功能：

```mermaid
sequenceDiagram
participant Client as 客户端
participant Proxy as 代理中间件
participant Auth as 认证服务
participant API as API服务
Client->>Proxy : 请求受保护资源
Proxy->>Proxy : 检查白名单路径
Proxy->>Proxy : 从Cookie获取token
Proxy->>Auth : 验证token有效性
Auth-->>Proxy : 返回验证结果
alt token有效
Proxy->>API : 转发请求
API-->>Proxy : 返回响应
Proxy-->>Client : 返回数据
else token无效
Proxy->>Client : 重定向到登录页
end
```

### API请求封装组件

统一的API请求封装提供了完整的HTTP通信能力：

```mermaid
flowchart TD
Start([请求开始]) --> CheckEnv{检查环境}
CheckEnv --> |客户端| ClientEnv[使用相对路径]
CheckEnv --> |服务端| ServerEnv[使用完整URL]
ClientEnv --> BuildHeaders[构建请求头]
ServerEnv --> BuildHeaders
BuildHeaders --> CheckToken{检查token}
CheckToken --> |客户端| GetTokenClient[从localStorage获取]
CheckToken --> |服务端| GetTokenServer[从cookies获取]
GetTokenClient --> AddAuth[添加认证头]
GetTokenServer --> AddAuth
AddAuth --> SendRequest[发送请求]
SendRequest --> CheckResponse{检查响应状态}
CheckResponse --> |2xx| ParseResponse[解析响应数据]
CheckResponse --> |401/403| HandleAuthError[处理认证错误]
CheckResponse --> |其他错误| HandleNetworkError[处理网络错误]
ParseResponse --> ReturnSuccess[返回成功响应]
HandleAuthError --> RedirectLogin[重定向到登录页]
HandleNetworkError --> ThrowError[抛出错误]
RedirectLogin --> End([请求结束])
ThrowError --> End
ReturnSuccess --> End
```

## 故障排除指南

### 常见部署问题

#### Vercel部署问题

1. **构建失败**
   - 检查环境变量配置
   - 验证package.json中的脚本命令
   - 确认Node.js版本兼容性

2. **运行时错误**
   - 检查NEXT_PUBLIC_*环境变量
   - 验证API端点可达性
   - 确认数据库连接配置

#### 自托管部署问题

1. **进程管理问题**
   - 检查PM2配置文件
   - 验证端口占用情况
   - 确认进程重启策略

2. **环境变量问题**
   - 验证.env文件配置
   - 检查权限设置
   - 确认变量格式正确

#### Docker部署问题

1. **镜像构建问题**
   - 检查Dockerfile语法
   - 验证依赖安装过程
   - 确认工作目录设置

2. **容器运行问题**
   - 检查端口映射配置
   - 验证卷挂载设置
   - 确认健康检查配置
